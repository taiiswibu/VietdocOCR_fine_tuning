# User-provided examples

The three PDFs and the screenshot were supplied by the user for local testing.
They are NOT the 5CD handwriting training dataset. These PDFs have native text layers.
The screenshot contains both a handwritten page and an existing OCR UI: crop the handwritten
page or a single line before benchmarking, otherwise the detector will also read the UI text.
Review rights and private information before publishing this examples directory on GitHub.

handwriting-paper.png is the paper-only crop of the supplied screenshot, created for the end-to-end smoke run.
